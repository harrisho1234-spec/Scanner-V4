# Scanner V4

Installable Progressive Web App (PWA) with Barcode Scanner and live inventory synchronization.

## 📁 Repository Structure
```text
├── index.html           # Main Scanner V4 web app
├── manifest.json        # PWA configuration ("Scanner V4")
├── sw.js                # Service worker
├── icons/
│   ├── icon-192.png     # 192x192 app icon
│   ├── icon-512.png     # 512x512 app icon
│   └── icon.svg         # Vector icon
└── README.md
```

## 🚀 Easy GitHub Deployment (No Terminal Needed!)

1. **Create a GitHub Repository**:
   - Go to [GitHub](https://github.com) and create a repository named `scanner-v4`.
   - Set visibility to **Public**.
2. **Upload the Files**:
   - Click **Add file** > **Upload files**.
   - Drag and drop all files from this folder (`index.html`, `manifest.json`, `sw.js`, `README.md`, and the `icons` folder).
   - Click **Commit changes**.
3. **Turn on GitHub Pages**:
   - Click **Settings** > **Pages** in the left sidebar.
   - Under **Build and deployment** > **Source**, choose **Deploy from a branch**.
   - Set the branch to `main` and folder to `/ (root)`, then click **Save**.
4. In ~1 minute, your app will be ready at:
   `https://<your-username>.github.io/scanner-v4/`

## 📲 How to Install as an App

- **Android (Chrome)**: Open the URL, tap `⋮` (menu) > **Install App** or **Add to Home screen**.
- **iOS (Safari)**: Open the URL, tap **Share** (square with up arrow) > **Add to Home Screen**.
- **Desktop (Chrome / Edge)**: Click the **Install** button on the address bar.
